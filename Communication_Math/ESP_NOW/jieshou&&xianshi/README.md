# ESP-NOW 接收与显示工程

本工程实现了如下功能：

- 作为 ESP-NOW 接收端，接收来自发送端（如 serial_espnow_project）的结构体数据。
- 支持的数据结构为：sudu1, x, y, sudu2（每个字段最多6个字符，空字段为"e"）。
- 通过 LVGL 图形界面在 LCD 屏幕上实时显示接收到的数据。
- 如果某个字段为 "e"，则界面上该项保持上一次的显示内容不变。
- 适用于无线传感器数据展示、远程监控等场景。

## 使用说明

1. 烧录本工程到 ESP32 设备，并连接 LCD 屏幕。
2. 启动后自动初始化 ESP-NOW 和 LVGL 显示界面。
3. 与发送端配对后，接收数据并在界面上实时显示。
4. 可配合 serial_espnow_project 工程实现无线数据采集与展示。
