# sendtest 项目说明

本项目包含两个子工程，配合实现串口到无线（ESP-NOW）数据转发与显示：

## 1. zhuanfa
- 作为发送端。
- 通过 USB-Serial/JTAG 串口接收字符串数据。
- 支持两种数据格式：
  - 带标签格式：`sudu1:123.4,x:567.8,y:901.2,sudu2:345.6`
  - 简单格式：`123.4,567.8,901.2,345.6`（空字段自动填"e"）
- 解析为结构体（sudu1, x, y, sudu2），每个字段最多6个字符。
- 通过 ESP-NOW 协议无线发送结构体数据到接收端。

## 2. jieshou&&xianshi
- 作为接收端。
- 通过 ESP-NOW 接收来自发送端的结构体数据。
- 支持字段：sudu1, x, y, sudu2（每个字段最多6个字符，空字段为"e"）。
- 通过 LVGL 图形界面在 LCD 屏幕上实时显示接收到的数据。
- 如果某个字段为"e"，则界面上该项保持上一次的显示内容不变。

## 配合使用方法
1. 将 zhuanfa 烧录到一块 ESP32 s3 板卡，作为数据发送端。
2. 将 jieshou&&xianshi 烧录到esp32-s3-touch-lcd2,作为数据接收与显示端。
3. 通过串口工具向发送端输入数据，数据会被解析并通过 ESP-NOW 发送到接收端。
4. 接收端收到数据后，实时在屏幕上显示。

适用于无线传感器数据采集、远程监控等场景。
