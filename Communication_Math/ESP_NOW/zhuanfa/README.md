# 串口转 ESP-NOW 发送工程

本工程实现了如下功能：

- 通过 USB-Serial/JTAG 串口接收字符串数据。
- 支持两种数据格式：
  1. 带标签格式：`sudu1:123.4,x:567.8,y:901.2,sudu2:345.6`
  2. 简单格式：`123.4,567.8,901.2,345.6`（支持空字段，空字段会被填为"e"）
- 解析串口数据为结构体（sudu1, x, y, sudu2），每个字段最多6个字符。
- 通过 ESP-NOW 协议将结构体数据无线发送到指定的接收端。
- 适用于无线传感器数据转发、远程监控等场景。

## 使用说明

1. 烧录本工程到 ESP32 设备。
2. 通过串口工具向设备发送数据，数据会被解析并通过 ESP-NOW 发送。
3. 可配合接收端（test1.0 工程）实现无线数据展示。
