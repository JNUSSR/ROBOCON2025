# Ball_Delivery 模块说明

本装置用于 3508 电机驱动的送球装置，将球从初始位置送到发射装置。

## 功能简介
- 启动后，装置会立即将球送到目标位置（发射装置）。
- 保持在目标位置1.8秒。
- 两秒后，装置自动回到初始位置，等待下一次操作。

## PID参数说明
本装置在不同运动阶段采用不同的PID参数：
- **送球阶段**：为实现快速、精准的送球动作，角度环和速度环均采用较高的PID增益参数，使电机能够快速响应并到达目标位置。
- **回到初始位置阶段**：由于回位过程中存在重力辅助，且对速度和冲击要求较低，因此采用较小的PID参数，使电机平稳缓慢地回到初始位置，避免因惯性或过大响应造成机械冲击。

## 运行逻辑与状态切换
- 代码上电后，默认执行一次“送球→归位”完整循环。可以通过修改 `motion_stage` 的初始值为 1，使系统上电后直接进入归位模式。
- `motion_stage` 变量作为送球与回到初始位置的状态标志位：
  - `motion_stage = 0` 表示送球阶段
  - `motion_stage = 1` 表示回到初始位置阶段
- 后续可通过串口通信修改 `motion_stage` 的值，实现对运动状态的远程切换和控制。

## 适用场景
适用于需要将球精准、快速送到发射机构的机器人系统。
