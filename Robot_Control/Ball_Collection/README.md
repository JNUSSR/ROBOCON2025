# Ball_Collection 模块说明

本模块用于投球机器人上的篮球收集装置，采用大疆 2006 电机（配合 C610 电调），通过 CAN1 总线控制。

## 硬件配置
- 使用 2 个大疆 2006 电机，均配备 C610 电调
- 电机连接在 CAN1 总线上，ID 分别为 6 和 7

## 功能简介
- 该装置用于接收运球车传来的篮球
- 启动后，两个 2006 电机协同工作，提拉（转动 10π，即 5 圈），使篮球滚入送球装置
- 提拉动作完成后，保持约 4 秒，随后自动复位到初始位置，等待下一步操作

## 运行逻辑与状态切换
- 通过标志位 `Collect_Stage` 控制收集与复位流程：
  - `Collect_Stage = 0`：收集阶段，电机执行提拉动作
  - `Collect_Stage = 1`：复位阶段，电机回到初始位置
- 系统上电后，`Collect_Stage` 的初始值为 0，默认执行一次“收集→复位”完整循环。可通过修改 `Collect_Stage` 的初始值为 1，使系统上电后直接进入复位模式。
- 后续可通过串口通信等方式修改 `Collect_Stage` 的值，实现远程切换和控制。

## 注意事项
- **当前参数和实际效果尚未在整车上测试，后续将根据实际测试结果进行调整和优化。**
- 电机转动的方向尚未最终确定，实际装车后需根据效果调整。
- 提拉转动的角度（10π）和 PID 参数也需要根据实际运行情况进行微调。
